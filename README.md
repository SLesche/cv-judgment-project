# Judging a book by its cover - investigating resume-based judgments of personality and intelligence
This repository contains the data and code for reproducing all results reported in our paper "Judging a book by its cover - investigating resume-based judgments of personality and intelligence".

All data preparation and analysis is conducted in the scripts [`final_code.R`](scripts/final_code.R), and [`final_code_s2.R`](scripts/final_code_s2.R).

The submitted manuscript deviates from the knit document only in format. To replicate the submission, begin by cloning this repository, installing the relevant packages and executing [`0_knit_document.R`](0_knit_document.R).
